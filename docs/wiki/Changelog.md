# Changelog

The full list is in [CHANGELOG.md](https://github.com/anand34577/noisefree/blob/main/CHANGELOG.md).

## 1.1.0 (2 November 2026)

A smaller window with its own title bar, a cleaner microphone list, and NoiseFree now comes back after a restart exactly as you left it: window open or in the tray, same place on screen, same settings, including **Hear yourself**.

## 1.0.1 (2 November 2026)

First release with downloads. Same features as 1.0.0, plus a fix for the BlackHole installer download on macOS, which the server was refusing.

## 1.0.0 (2 November 2026)

First release. Real-time noise removal with the DTLN model on Windows, macOS and Linux, running on a GPU when available and the CPU otherwise. Includes a virtual microphone for meeting apps, in-app driver install, level meters, a strength slider, monitoring through headphones, tray mode and launch at sign-in.
