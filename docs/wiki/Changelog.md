## 1.0.0 (2 November 2026)

First release. Real-time noise removal with the DTLN model on Windows, macOS and Linux, running on a GPU when available and the CPU otherwise. Includes a virtual microphone for meeting apps, in-app driver install, level meters, a strength slider, monitoring through headphones, tray mode and launch at sign-in.
